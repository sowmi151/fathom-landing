## 💻 How to Run Locally

To view this project on your own computer:

1. **Clone the repository:**
```bash
git clone https://github.com/sowmi151/fathom-landing.git

```


2. **Open in VS Code:**
Navigate to the folder and open it in your code editor.
3. **Launch with Live Server:**
Right-click `index.html` in VS Code and select **Open with Live Server** to view it in your browser.
