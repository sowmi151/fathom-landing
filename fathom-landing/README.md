# Fathom – Landing Page

Static landing page for "Fathom", a fictional countertop water filter with a built-in sensor.
HTML5 + CSS3 only, no JavaScript, no external dependencies.

## Structure
```
fathom-landing/
├── index.html
├── css/style.css
├── assets/favicon.svg
└── README.md
```

## Run
Open `index.html` in any browser.

## Checklist
- Sticky nav with 4 links (Features, How it works, Reviews, Order)
- Hero: headline, subheadline, CTA button
- 3 content sections: Features, How it works, Reviews (plus closing CTA)
- Footer with contact and social placeholders
- Palette via CSS variables (ink blue, foam, sun yellow)
- Responsive with Flexbox + Grid (breakpoints 820px, 560px)
- Global `box-sizing: border-box`, spacing scale for padding/margin
- Typography: Georgia headings, system sans body, fluid heading sizes
